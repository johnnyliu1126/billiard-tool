# 中式八球解球工具 — 设计规格

## 概述

一个手机端纯前端网页工具，帮助中式八球玩家在打球时快速计算多颗星解球路线，避开障碍球将目标球打入指定袋口。

## 技术栈

- 单个 HTML 文件，内嵌 CSS + JS
- Matter.js CDN 作为 2D 物理引擎
- Canvas 绘图，支持触摸交互
- 无需构建工具，无需后端，浏览器打开即用

## 核心功能

### 1. 桌面布球

- 以中式八球桌为标准：内径 2540mm × 1270mm（按比例缩放到屏幕）
- 支持拖拽和点击两种方式放置球
- 球类型：母球（白色）、目标球（纯色）、障碍球（条纹）、袋口标记
- 每种球用不同颜色区分

### 2. 颗星解球计算

- 利用镜像法（mirror method）计算多颗星反弹路线
  - 将桌面沿颗星做镜像，反弹问题转化为直线问题
  - 找到连接母球和目标球（经过镜像）的直线
  - 支持 1 星、2 星、3 星、4 星、5 星解球
- 对镜像法找到的路线，用 Matter.js 进行物理模拟验证
- 考虑障碍球：排除与障碍球碰撞的路线

### 3. 路线可视化

- 在桌面上绘制解球路线（虚线 + 实线）
- 标注颗星击打点
- 物理模拟动画展示球的运动轨迹
- 多条可行路线时展示最优方案

### 4. 操作功能

- 计算路线按钮
- 清空桌面按钮
- 撤销/恢复
- 球类型选择工具栏

## 桌面坐标系

- 中式八球桌内径比例 2:1（2540mm × 1270mm）
- 6 个袋口：四角 + 两腰
- Canvas 坐标映射：桌面长边占屏幕宽度的 90%，短边按比例缩放
- 球直径按标准 57.15mm 等比缩放

## 镜像法计算逻辑

1. 根据选择的颗星数 N（1-5），生成所有可能的反弹序列（如 3 星：长边→短边→长边；5 星：长→短→长→短→长）
2. 对每条序列，沿对应颗星做 N 次镜像翻转
3. 在镜像空间中，母球到目标球的直线即为反弹路线
4. 将镜像路线映射回真实桌面，得到颗星击打点坐标
5. 过滤：排除击打点超出颗星范围的路线、与障碍球碰撞的路线

## 物理模拟逻辑

1. 将镜像法算出的路线转换为击球方向和力度
2. 用 Matter.js 创建母球、目标球、障碍球
3. 给母球施加初始速度
4. 运行物理引擎，记录球的运动轨迹
5. 碰撞检测：判断目标球是否入袋、是否碰到障碍球

## 交互逻辑

- **点击模式**：先选球类型，点击桌面空位放置，拖拽已放置的球移动
- **拖拽模式**：从工具栏长按拖出球到桌面
- 袋口标记点击袋口位置即可放置
- 支持双指缩放和拖拽移动视角（可选）
