# 左右赛 2.5D 物理模型设计

## 目标

让左/右赛在出杆与碰库时产生稳定、方向正确且可校准的差异，同时保持当前纯前端、二维 Canvas 应用的轻量特性。

本次不尝试复现职业级完整 3D 台球物理；特别是不包含球球碰撞 throw、跳球、塞球后的 swerve 曲线或库边橡胶压缩形变。

## 现状与根因

当前物理状态只有一个 `omega`。高/低杆和左/右赛都写入该变量，无法表达两个不同的旋转轴。模拟开始时，左右赛额外把出杆角度固定改为 `±0.05` 弧度；库边反弹的侧旋系数则固定为 `0`。因此，左右赛现在主要是瞄准偏移，碰库轨迹没有受侧旋影响。

## 方案

采用二维平动加独立垂直自转轴的 2.5D 模型：

- 保留现有 `omega`，继续承载高/低杆和滑动/滚动的既有近似，避免本次改变高低杆行为。
- 每颗物理球新增 `sideOmega`，单位为弧度/秒，表示绕台面法线方向的自转。只有母球在出杆时拥有初始侧旋。
- 左右赛的强度由杆头横向击球点导出；工具栏按钮与瞄准面板保持同步。
- 移除当前固定 `±0.05` 的瞄准偏移。改为一个速度和横向击球点相关、集中配置的 squirt 角度，以表达偏杆后母球偏离球杆线的现象。
- 台呢阶段以独立指数衰减降低 `sideOmega`，不让侧旋永久存在。
- 碰库时，按库边切线速度、`sideOmega` 和法向入射速度计算有上限的切向摩擦冲量。该冲量同时改变反弹切向速度与 `sideOmega`，所以顺塞和反塞会产生相反的反弹角变化，并会在每次碰库后损失侧旋。
- 零侧旋时，库边反射沿用当前结果，避免影响现有无赛路线。

## 数学约定

对每次库边接触，使用指向台内的单位法线 `n` 和切线 `t = (-n.y, n.x)`：

- `vn = dot(v, n)` 是法向速度；沿当前逻辑以恢复系数处理。
- `vt = dot(v, t)` 是切向速度。
- 接触点的相对切向滑动速度为 `vt - sideOmega * ballRadius`。
- 根据库边摩擦系数和法向冲量限制切向冲量；冲量优先减少相对滑动，随后按实心球转动惯量比例反向更新 `sideOmega`。

此约定保证在镜像球位中交换左、右赛时，反弹偏移镜像对称。UI 对“左/右”的具体映射由该对称测试锁定，避免屏幕坐标方向导致语义反转。

## 参数与可校准性

在 `index.html` 中集中定义以下常量，并在旁边标明其含义和单位：

- `PHYS_SQUIRT_MAX_ANGLE`：满赛的最大出杆偏移角。
- `PHYS_SIDE_SPIN_MAX`：满赛的初始 `sideOmega`。
- `PHYS_SIDE_SPIN_DECAY`：台呢上的侧旋衰减率。
- `PHYS_CUSHION_TANGENTIAL_FRICTION`：库边切向摩擦系数。
- `PHYS_CUSHION_SIDE_SPIN_RETENTION`：碰库后侧旋保留比例。

初始值以当前球速范围（1–10 m/s）下的稳定、可见差异为目标，不把任意一张球台的经验数据伪装成通用真值。后续可通过同一球台的慢动作视频校准这些系数。

## 文件边界

- 新增 `side-spin-physics.mjs`：只包含无 DOM 依赖的侧旋强度、squirt 和库边切向冲量计算。
- 新增 `tests/side-spin-physics.test.mjs`：使用 Node 内置测试运行器验证纯计算函数。
- 修改 `index.html`：以模块方式导入计算函数，为物理球加入 `sideOmega`，并替换现有固定偏瞄及零侧旋库边反射。
- 修改 `README.md`：把“赛（左/右）”说明为“近似侧旋模型”，写明其包含的效果与当前不包含的效果。

## 验收与回归测试

1. 零侧旋的库边反弹不产生额外切向速度变化。
2. 在镜像场景中，左赛与右赛的反弹偏移大小相等、方向相反。
3. 相同球位和速度下，满赛产生的偏移大于半赛；侧旋随时间和每次碰库减小。
4. squirt 角度随横向击球点增大而增大，左/右方向相反；中心击球点为零。
5. 浏览器中原有 1–5 颗星计算、无赛物理模拟与音效继续可用。

## 不在本次范围

- 球球碰撞的侧旋 throw 与目标球偏移。
- 真实库边鼻线、形变、跳球和台呢导致的曲线运动。
- 通过摄像头自动校准球台参数。
