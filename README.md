# 中式八球解球工具

手机端台球解球计算工具，帮助你在打球时快速计算多颗星解球路线，避开障碍球将目标球打入指定袋口。

## 在线使用

**https://johnnyliu1126.github.io/billiard-tool/**

手机浏览器打开即用，无需安装。

### 拍照自动识别

1. 先选择需要的颗星数，再点击顶部「📷 拍照」
2. 从球桌上方拍摄，让整块台呢与四个角完整入镜，并尽量避开灯光反射
3. 工具先给出识别初稿，并在原照片上保留台面四角和球心标记
4. 用「四角、移动球心、补球、删误检、指定母球」完成校正；四角改变后可按当前范围重识别
5. 明确点选所有合法目标球，未选球会作为障碍参与计算；工具不会猜测你应打全色还是花色
6. 点击「应用并计算」，再用当前速度、杆法和旋转运行模拟验证

照片全程在当前浏览器内处理，不会上传到服务器。

## 使用方法

1. **放置母球** — 选中工具栏「⚪ 母球」，点击桌面放置
2. **放置目标球** — 选中「🔵 目标」，点击桌面放置
3. **放置障碍球**（可选）— 选中「🔴 障碍」，点击桌面放置
4. **设置目标袋口** — 选中「⭕ 袋口」，点击目标袋口位置
5. **选择颗星数** — 底部工具栏选择 1-5 星
6. **计算路线** — 点击「计算路线」
7. **选择路线** — 多条路线时，点击底部路线芯片或桌面颗星点切换
8. **模拟验证** — 点击「模拟验证」设置连续击球点、速度与杆法，查看运动轨迹和指定袋结果

## 操作技巧

- **拖拽移动**：按住球拖拽可移动位置
- **精细调整**：照片校正中先选中球，再用方向按钮每次微调 2 像素
- **长按删除**：长按球 0.6 秒可删除
- **路线选择**：计算后点击桌面上的颗星点圆圈，或底部路线标签切换路线
- **路线颜色**：黄色为最佳路线，依次为红、青、橙、紫，选中路线高亮显示
- **颗星点标注**：路线上标注的数字表示击打颗星的顺序
- **击球控制**：可调节出杆速度（1-10 m/s）、杆法（高/中/低）、赛（左/右）

## 技术说明

- 镜像法（Mirror Method）计算颗星解球路线，考虑球半径的幽灵库边；路线按切球角、行程、障碍余量、母球落袋风险和小幅球位扰动容错排序
- 自研 2.5D 物理引擎：带符号的滑动/滚动摩擦、跟进/退杆、侧旋库边冲量和高速自适应小步长碰撞
- 模拟使用固定物理时步，不受手机屏幕刷新率影响；判定会区分指定袋、错袋和母球落袋
- 路线计算会排除提前碰到目标球、幽灵球出界和目标球被实体库边挡住的伪路线
- 拍照功能通过台呢颜色分割、四角透视校正和球体色差检测，将图像坐标换算为中式八球台毫米坐标
- “中八标准”物理参数综合 CBSA 尺寸、pooltool 八球基线和公开碰库实验；高速时自动降低简化库边恢复系数
- 纯前端实现，无需服务器，离线可用
- 球位、目标袋、颗星数和击球设置会保存在当前浏览器，刷新后可继续
- GitHub Pages 自动部署

## 模型边界

路线适合现场辅助判断，不替代球桌校准。几何扰动样本表示路线对小幅录入误差的容忍度，不是实际进球率。台呢速度、库边弹性、杆头偏移和球的洁净程度都会影响真实结果；袋角目前采用简化直线袋口模型。照片识别是需要人工复核的初稿，遮挡、强反光、球杆和过低拍摄角度仍会造成漏检或误检。公开参数来源和真实照片验证记录见 [物理参数基线](docs/physics-baselines.md) 与 [照片识别验证](docs/photo-validation.md)。
