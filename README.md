# 中式八球解球工具

手机端台球解球计算工具，帮助你在打球时快速计算多颗星解球路线。

## 使用方法

1. 在手机上用浏览器打开 `index.html`
2. **放置母球** — 选中工具栏「⚪ 母球」，点击桌面放置
3. **放置目标球** — 选中「🔵 目标」，点击桌面放置
4. **放置障碍球**（可选）— 选中「🔴 障碍」，点击桌面放置
5. **设置目标袋口** — 选中「⭕ 袋口」，点击目标袋口位置
6. **选择颗星数** — 底部工具栏选择 1-5 星
7. **计算路线** — 点击「计算路线」
8. **物理模拟** — 点击「物理模拟」查看真实运动轨迹

## 操作技巧

- **拖拽移动**：按住球拖拽可移动位置
- **长按删除**：长按球 0.6 秒可删除
- **路线颜色**：黄色为最佳路线，依次为红、青、橙、紫
- **颗星点标注**：路线上标注的数字表示击打颗星的顺序

## 技术说明

- 使用镜像法（Mirror Method）计算颗星解球路线
- Matter.js 物理引擎模拟真实球的运动
- 纯前端实现，无需服务器，离线可用
